## Ruling log

Decisions taken after the plan was written, during the review and fix waves:

1. **Unimplemented E2E workflows fail, they do not pass silently.** Seven tests whose bodies were `pass` now `pytest.fail` with the workflow they would exercise, and five print-only tests gained assertions. "Not implemented is a flavor of broken" applies to a measurement that never compares against anything. This moves the live gate from 151/6/0 to 144/6/7.
2. **The stale Firecracker API socket is unlinked on kill.** Added to the product-change list below: `FirecrackerHypervisor` tracks pid -> socket path and removes the file when the VM is killed, and `scripts/e2e.sh` sweeps `/tmp/fc-*.socket`. The live host had accumulated 1391 stale sockets against zero firecracker processes.

The "product changes in this PR are exactly" constraint below is to be read as including both of these.

**Goal:** Complete the three test tiers the spec defines (§11): unit coverage for every host implementation and every leaf module, the full flow matrix through HTTP on the fake host, the two E2E assertion tightenings, and a coverage floor enforced in CI; and close the small product nits parked by the PR 3 and PR 4 reviews (exec timed on two series, rootfs post-processing on the event loop, the duplicate OpenAPI operation id, shell chaining in the E2E account step, the unclosed unit-test client).

**Architecture:** No new product surface. Tests are added tier by tier with the seams that already exist: injected `run` recorders for the shell-driven host modules, injected `connect` and a `FakeConn`/`FakeSftp` for the SSH guest, `httpx.MockTransport` for the Firecracker API client, a fake `firecracker` binary script for the process helpers, and the fake host plus the real ASGI app for flows. Three tiny seams are added to `src/` because nothing else can reach the code (`FirecrackerClient(transport=)`, `start_firecracker_process(binary=, socket_timeout=)`, `RateLimiter(clock=)`), and `FakeBlockStore.mounted` gains a stable per-device directory so merge tests can see file content. Shared row builders move to `tests/support.py`; unit tests get a `runtime` fixture that closes what it opens.

**Tech Stack:** Python 3.12, pytest 9 / pytest-asyncio 1.3 / pytest-cov, httpx, FastAPI, asyncssh types (faked), starlark_go, uv, ruff 0.15, mypy 1.19 strict.

**Spec:** `docs/superpowers/specs/2026-09-04-quality-overhaul-design.md` §10 (metric series), §11 (test tiers, E2E changes, coverage floor), §12 (CI runs `pytest -m "not e2e" --cov`), §14 step 5. Deviations decided here:

1. **Host unit tests patch module seams.** The Firecracker hypervisor calls `start_firecracker_process`, `wait_for_port`, `kill_firecracker_process`, `FirecrackerClient`, and `asyncssh.connect` as module-level names; those are the host boundary's own edges, so the hypervisor tests monkeypatch them on `mshkn.host.firecracker`. The PR 4 rule "no module-level patching" stays in force for the flow tier.
2. **Three injection seams added to `src/`:** `FirecrackerClient(socket_path, *, transport=None)`, `start_firecracker_process(socket_path, *, binary="firecracker", socket_timeout=2.0)`, `RateLimiter(max_requests, window_seconds, *, clock=time.monotonic)`. Defaults keep production behaviour byte-identical.
3. **`mshkn_exec_duration_seconds` is retired.** §10's table lists `mshkn_operation_duration_seconds{op="exec"}` and nothing else for exec; the SSE path now runs under `timed("exec")` like `ComputerService.exec`. The E2E observability test asserts only `mshkn_computers_active`, and its docstring's mention of the old series is updated.
4. **`FakeBlockStore.mounted` yields a stable directory per device name** (content persists across mounts, as on a real device) and records `("mounted", (name, readonly))` in `calls`, so the merge walk and the mount order are testable. Unmapped names still raise `HostError`.
5. **The ingress trigger is declared once per method** (`@router.get/post/put/patch` stacked on one handler) instead of `api_route(methods=[...])`, which gave four operations the same id and a FastAPI warning; the path and behaviour are unchanged.

from __future__ import annotations

import asyncio
import os
from pathlib import Path

import pytest

from mshkn.host.firecracker import (
    kill_firecracker_process,
    start_firecracker_process,
    wait_for_port,
)


def _fake_binary(tmp_path: Path, *, creates_socket: bool) -> str:
    script = tmp_path / "fake-firecracker"
    body = "#!/bin/bash\n"
    if creates_socket:
        body += 'shift; touch "$1"\n'  # argv: --api-sock <path>
    body += "sleep 30\n"
    script.write_text(body)
    script.chmod(0o755)
    return str(script)


async def test_start_returns_a_live_pid_and_kill_reaps_it(tmp_path: Path) -> None:
    socket_path = str(tmp_path / "fc.socket")
    Path(socket_path).write_text("stale")  # a stale socket file is removed first
    pid = await start_firecracker_process(socket_path, binary=_fake_binary(tmp_path, creates_socket=True))
    assert os.path.exists(socket_path)
    os.kill(pid, 0)  # alive
    await kill_firecracker_process(pid)
    with pytest.raises(ProcessLookupError):
        os.kill(pid, 0)


async def test_start_times_out_when_the_socket_never_appears(tmp_path: Path) -> None:
    socket_path = str(tmp_path / "never.socket")
    with pytest.raises(TimeoutError, match="not created"):
        await start_firecracker_process(
            socket_path, binary=_fake_binary(tmp_path, creates_socket=False), socket_timeout=0.2
        )


async def test_kill_of_a_dead_pid_is_a_no_op() -> None:
    proc = await asyncio.create_subprocess_exec("true")
    await proc.wait()
    await kill_firecracker_process(proc.pid)  # no exception


async def test_wait_for_port_returns_when_a_listener_answers() -> None:
    server = await asyncio.start_server(lambda r, w: w.close(), "127.0.0.1", 0)
    port = server.sockets[0].getsockname()[1]
    try:
        await wait_for_port("127.0.0.1", port, timeout=2.0)
    finally:
        server.close()
        await server.wait_closed()


async def test_wait_for_port_times_out_on_a_closed_port() -> None:
    server = await asyncio.start_server(lambda r, w: w.close(), "127.0.0.1", 0)
    port = server.sockets[0].getsockname()[1]
    server.close()
    await server.wait_closed()

async def start_firecracker_process(
    socket_path: str, *, binary: str = "firecracker", socket_timeout: float = 2.0
) -> int:
    with contextlib.suppress(FileNotFoundError):
        Path(socket_path).unlink()
    proc = await asyncio.create_subprocess_exec(
        binary, "--api-sock", socket_path,
        stdout=asyncio.subprocess.DEVNULL, stderr=asyncio.subprocess.DEVNULL,
    )
    loop = asyncio.get_running_loop()
    deadline = loop.time() + socket_timeout
    while loop.time() < deadline:
        if Path(socket_path).exists():
            break
        await asyncio.sleep(0.01)
    else:
        raise TimeoutError(f"Firecracker socket {socket_path} not created within {socket_timeout}s")
    logger.info("Started Firecracker process PID=%d socket=%s", proc.pid, socket_path)
    return proc.pid
